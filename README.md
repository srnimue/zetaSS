# Zetaスクショ黒塗りツール v6

Zetaのスクリーンショットをブラウザ内だけで加工する簡易ツールです。

## v6の変更点
- 右端の丸アイコンだけを自動検出
- アイコン付近の小さい名前もOCR結果から自動検出
- OpenCV.jsを必要なときだけ読み込む方式に変更
- OpenCV.jsの初期化を正しく待機
- OpenCV.jsの読み込み待ちを15秒から60秒に延長

## 使い方
1. HTMLをGitHub Pagesなどで公開
2. スクリーンショットを選択
3. 黒塗りする文字を入力
4. 必要なら「右端の丸アイコンも黒塗り」をON
5. 「OCRして黒塗り」
6. 「PNGで保存」

画像処理はブラウザ内で行い、画像をこのツールのサーバーへアップロードしません。
