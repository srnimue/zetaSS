# スクショ黒塗りツール V68

V55をベースに、拡大時の画像移動と表示まわりを調整した版です。

- 手動黒塗りを移動
- 四隅からサイズ変更
- ダブルタップ／ダブルクリックで個別削除
- 手動操作のUndoを編集・追加・削除に対応
- OCR処理、jpnモデル、既存のUI・ジェスチャーは維持

- 拡大時の画像移動範囲を改善
- 実行ステータスの文字サイズを調整
- 共有時の「Zetaスクショ」タイトルを削除
- アプリ表示名から「Zeta」を削除


V62は実験版です。OCRで1件正しく見つかった文字画像をテンプレートとして同じ見た目の領域を探索します。候補は診断に表示するだけで、自動黒塗りにはまだ採用しません。


V68実験版：V64の文字領域推定を維持し、通常の局所OCRで対象文字を見つけられなかった領域だけ、グレー＋コントラスト・二値化180・反転の3種類を追加して局所OCRします。追加結果は診断専用で、自動黒塗りには使用しません。


V68: V64の文字領域検出で得られた全候補を通常局所OCRし、上位16領域制限による見落としがないか確認する診断実験。前処理追加・黒塗りへの使用は行わない。


## V75実験内容
V70の文字領域局所OCRを維持し、局所OCR結果について「対象文字と同じ文字数で1文字だけ異なる」候補を診断表示します。候補のbboxはOCRが返した該当文字単位から作成し、候補地点全体は黒塗りしません。V75ではこの近似候補をまだ自動黒塗りには使用しません。
