# V91.13 黒塗り幅安定化テスト

V91.12 の軽量構成をベースに、短名（1〜3文字）の最終黒塗り矩形だけを最小変更で調整したテスト版です。

- 細すぎる判定を expectedW × 0.78 → 0.88 に変更
- expand-left 発動時は追加の左paddingを 2px 固定にして二重加算を防止
- 基本幅は従来どおり高さ基準
- word-splitではないsymbol幅が2個以上あり、max/min <= 1.35 の時だけ中央値幅を補助利用
- 実測利用時は medianCharW × 文字数 × 1.05
- OCR検出・局所OCR・イタリック探索・手動編集には変更なし

確認ポイント：ネル（左残り/expand-left過剰）、真緒・伊織（右食い込み）が悪化しないか。
