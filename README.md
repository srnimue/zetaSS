# Zetaスクショ黒塗りツール v5

Zetaのスクリーンショットから、指定した名前をOCRで探して黒塗りするブラウザ用ツールです。

## v5の変更点

- 顔アイコンを固定座標ではなく画像解析で自動検出
- 画像サイズが変わってもアイコン位置を自動判定
- 左右端にある複数の顔アイコンを検出可能
- 顔アイコン付近に表示される小さい名前もOCR結果から自動検出して黒塗り
- アイコンへの `{{user}}` 表示は従来どおりON/OFF可能
- Tesseract.js + OpenCV.jsをブラウザ内で使用
- 画像そのものはサーバーへアップロードしません

## 使い方

1. HTMLをブラウザで開く
2. スクリーンショットを選択
3. 黒塗りしたい名前を入力
4. 必要なら「黒塗り部分に置き換え文字を表示」をON
5. 必要なら「右端の丸アイコンも黒塗り」をON
6. 必要なら「アイコン部分にも置き換え文字を表示」をON
7. 「OCRして黒塗り」を押す
8. 「PNGで保存」を押す

## 注意

初回はTesseract.jsとOpenCV.jsの読み込みに時間がかかる場合があります。GitHub Pagesなど、インターネットへ接続できる環境で使用してください。

アイコン検出は画像解析による自動判定なので、特殊なUIや非常に小さいアイコンでは誤検出・検出漏れが起こる可能性があります。
