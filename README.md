# スクショ黒塗りツール V91

スクリーンショット内の指定文字をOCRで検出し、黒塗り・背景色・ぼかし・任意色で隠すブラウザツールです。GitHub Pagesで動作するクライアントサイド構成で、画像はサーバーへ送信しません。

## V90.27 テスト内容

- まず解析用の基準キャンバスを1枚作り、全体OCR・文字領域局所OCR・イタリック救出を同じ座標系で処理する実験版です。
- 解析キャンバスは最大幅1000px / 最大250万px。大きい画像だけ縮小し、小さい画像は原寸のままです。
- OCRだけは基準キャンバスから別途拡大して実行し、精度をなるべく落とさずに最後に元画像座標へ戻します。
- 診断表示にも解析キャンバス情報を追加し、条件が揃っているか確認しやすくしました。

## 主な機能

- 日本語OCRによる指定文字の自動検出
- 1〜3文字程度の短い日本語名を優先した黒塗り幅補正
- 近似候補救出、文字領域局所OCR、イタリック補助探索
- 手動黒塗り、なぞり式、スタンプモード
- 黒塗り / 背景色 / ぼかし / 任意色
- OCR後の矩形を移動・リサイズ・削除可能
- iPhone/iPadでは共有シート、PCでは保存ダイアログまたはPNGダウンロード

## V90.24 テスト内容

- word均等分割へフォールバックした1〜3文字の日本語名について、bboxが文字高さに対して過大な場合だけ右端を縮める軽量な幅ガードを追加。左端は固定し、先頭文字の露出を避けます。追加OCRは行いません。
- 3文字名の1文字誤認を複数地点の一致で救出するロジックを維持しています。
- 本番のイタリック探索は速度維持のため従来どおり追加skew 0.00の1本だけです。OCR診断時のみ -0.10 / 0.00 / +0.10 を比較し、Zetaの斜体に追加skewが有効かを確認できます。

## 手動操作

- 1本指: 黒塗りの作成・編集
- 2本指: 移動・ピンチズーム
- 選択した矩形: 中央ドラッグで移動、四隅でサイズ変更
- 選択中の ×: 削除
- スタンプモード: 直前の手動矩形と同じサイズをタップ位置へ追加

## V91 黒塗りきれいきれい編

検出ロジックはV90.27系を維持し、拾えた名前の最終黒塗り矩形を優先して調整する版です。

- 1〜3文字の日本語名は左余白を少し増やし、先頭文字の露出を防止
- 正常なsymbol bboxでは右余白を0pxにし、後続の「さん」「ちゃん」「くん」等を巻き込みにくく変更
- word均等分割時のみ右に1pxを残す
- 局所OCRで短名bboxが縦長になる場合、文字幅を基準に高さを整形
- 局所OCR短名の横幅が過大な場合は左端固定で右側だけ縮小
- 手動編集、保存、統一解析キャンバスなど既存機能は維持
