# スクショ黒塗りツール V90.23

スクリーンショット内の名前をOCRで探し、黒塗り・背景色・ぼかし・任意色で隠すためのクライアントサイドWebアプリです。GitHub Pagesでそのまま動作し、画像はサーバーへ送信しません。

## 現在の方針

- 名前消し用途を優先し、特に日本語の1〜3文字名を扱いやすくする。
- 自動検出は速度を優先し、取りこぼしや数pxのズレは手動編集で補える構成にする。
- 重い全画面OCRの多重実行は避ける。
- iPhone Safariでの操作とメモリ使用量を重視する。

## 自動検出

- Tesseract.js v5 / 日本語OCR
- グレー＋コントラストの主OCR
- 色抽出OCR
- 近似候補の局所救出
- 文字領域の局所OCR
- コントラスト＋イタリック補助探索
- 大きな画像ではOCR用キャンバス倍率を自動調整

V90.23では、Tesseractのsymbol bboxが1文字だけ異常に横長い場合、座標を直接削るのではなく、そのword全体のbboxを文字数で均等分割してから対象文字の範囲を作ります。追加OCRは行わないため、速度への影響はほぼありません。

イタリック補助探索の採用条件は誤爆を避ける安全側の設定（score 0.62 / 形状 0.47 / 背景 0.93）です。

## 手動編集

- なぞり式 / 自由矩形
- スタンプモード
- 黒塗りをタップして選択
- 中央ドラッグで移動
- 四隅ドラッグでサイズ変更
- 選択中の「×」で削除
- 戻す
- 2本指でパン / ピンチズーム

## 保存

- iPhone / iPad系では共有シートを利用
- PCでは保存ダイアログ対応ブラウザなら保存先を選択
- 非対応ブラウザではPNGとして通常ダウンロード
