# スクショ黒塗りツール V57

スクリーンショット内の指定文字をOCRで探して自動で黒塗りし、必要に応じて手動で位置やサイズを調整できます。

## V57の変更点
- OCR検索時の表記揺れを吸収する正規化を強化
- 長音・ハイフン類を検索上で統一
- 空白・改行・記号類を検索から除外
- 通常の完全一致で見つからない場合だけ、限定的な誤認識候補を試す方式を追加
- 日本語の固有名詞などを優先するため、OCRの辞書補正（DAWG）を無効化して比較
- V56の拡大時の画像移動、編集可能な自動黒塗り、ステータス表示、共有動作を維持

## 基本操作
- 「✨ 自動検出」：指定文字をOCRで探して黒塗り
- 「🖊 手動」：手動で黒塗りを追加・編集
- 「↩️ 戻す」：直前の黒塗り操作を取り消し
- 「🗑」：黒塗りをすべて削除
- 2本指操作：画像の移動・拡大縮小
- 画像保存：iPhoneでは共有シートから保存先を選択

## 手動黒塗り
- 1本指：黒塗りを追加
- 既存の黒塗りをドラッグ：移動
- 四隅をドラッグ：サイズ変更
- ダブルタップ／ダブルクリック：個別削除

画像処理はブラウザ内で行い、画像をサーバーへアップロードする仕組みはありません。
