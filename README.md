# スクショ黒塗りツール V81

V76の「OCR前に白枠10px」をベースにした、誤認識救出の診断版です。

## V81で追加した実験
- かな・カタカナのみ、よく起きる少数のOCR誤認識を対象文字ごとに許容して候補化。
- 対象文字と1文字だけ異なるケースを、かなの範囲に限定して診断。
- 漢字は誤認識辞書による置換をまだ行わない。漢字は誤爆が増えやすいため、今後は文字形・位置・サイズなどを組み合わせた別方式を検討。
- V81の候補は診断表示のみで、黒塗りには使用しません。

## 使い方
1. 画像を選択
2. 対象文字を入力
3. 「OCR診断」を実行
4. 診断結果の「V81 誤認識救出診断（かな）」を確認

通常の黒塗り処理はV76相当のままです。
