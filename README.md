# Zetaスクショ黒塗りツール V19

OCRで指定文字を自動黒塗りし、取りこぼしを画像上のドラッグ操作で手動追加できるブラウザツールです。

## V19
- OCR診断で対象文字を構成するsymbol単位のbboxを表示。画像ごとのズレ方を比較できます。OCR認識・黒塗り処理そのものは変更していません。

- OCR自動黒塗り
- OCR取りこぼし用の手動長方形黒塗り
- 手動黒塗りを複数追加可能
- 直前の手動黒塗りを取り消し
- iPhone/iPadのWeb Share保存
- OpenCV.jsなし
- Tesseract.js 5をCDNから読み込み

GitHub Pagesでは `index.html`、`app.js`、`style.css` を同じ場所に置いてください。


V19: 直前の手動黒塗りと同じサイズでタップ配置できるスタンプモードを追加。チェックボックスでON/OFFできます。


V19: OCR自動塗りつぶしの左端を独立して調整できる `OCR_LEFT_TRIM` を追加。手動黒塗りには影響しません。

## V19
- OCR診断で対象文字を構成するsymbol単位のbboxを表示。画像ごとのズレ方を比較できます。OCR認識・黒塗り処理そのものは変更していません。

- canvasの表示位置・ズーム・スクロールを考慮した座標変換に修正。
- OCR診断の枠表示と手動選択枠が、中央寄せやズーム時でもcanvasと同じ座標系になるように修正。
- OCR自体の認識処理、対象文字のsymbol bbox、手動黒塗り処理はV17から変更なし。

## V17
- Tesseract.jsを日本語OCR（jpn）に変更。
- OCR用に2.5倍へ拡大した座標を、黒塗り時には元画像座標へ戻す処理を維持。
- 対象文字そのもののsymbol bboxを優先して使用し、単語全体を黒塗りしない。
- OCR診断で「単語bbox」と「対象文字bbox」を分けて確認できるようにした。
- 診断モードは残してあり、不要になったらindex.htmlの「OCR診断」ボタンと診断表示部分、app.jsのdiagnoseOCR関連をコメントアウトして運用可能。
