# スクショ黒塗りツール V72

V70.1をベースにした色領域抽出の実験版です。

## V72の追加実験
「🎨 色抽出診断」を追加しています。zetaの表示テーマで使われる文字色の傾向を利用して、白文字・グレー文字・暗色文字がありそうな横長領域を先に抽出し、その領域だけPSM7の局所OCRを行います。

この版では色抽出結果を自動黒塗りには接続していません。診断結果だけを見て、見落とし文字の救出に使えそうかを確認するための実験版です。

通常の「自動検出」「OCR診断」など、V70.1までの機能はそのままです。

## 使い方
1. スクリーンショットを選択
2. 黒塗りする文字を入力
3. 「🎨 色抽出診断」を押す
4. 下に出る診断結果を確認

## 注意
iPhone Safariでの処理負荷を確認する実験でもあるため、7個など多数の対象がある画像では無理に繰り返さず、まず少ない対象数の画像で試してください。
