# スクショ黒塗りツール V67

V55をベースに、拡大時の画像移動と表示まわりを調整した版です。

- 手動黒塗りを移動
- 四隅からサイズ変更
- ダブルタップ／ダブルクリックで個別削除
- 手動操作のUndoを編集・追加・削除に対応
- OCR処理、jpnモデル、既存のUI・ジェスチャーは維持

- 拡大時の画像移動範囲を改善
- 実行ステータスの文字サイズを調整
- 共有時の「Zetaスクショ」タイトルを削除
- アプリ表示名から「Zeta」を削除


V62は実験版です。OCRで1件正しく見つかった文字画像をテンプレートとして同じ見た目の領域を探索します。候補は診断に表示するだけで、自動黒塗りにはまだ採用しません。


V67実験版：V64の文字領域推定を維持し、通常の局所OCRで対象文字を見つけられなかった領域だけ、グレー＋コントラスト・二値化180・反転の3種類を追加して局所OCRします。追加結果は診断専用で、自動黒塗りには使用しません。
