# zetaSS V82.1

V81をベースにした診断版。
- かな誤認識候補を黒塗りには使用せず、候補bboxを赤枠で仮表示
- 診断見出しをV82.1へ更新
- 色抽出OCRを主OCRのHIT数に関係なく補助実行し、退行確認用にHIT数を表示
- 既存の手動黒塗り・OCR黒塗り処理は変更しない


V86.1: 手動描画の初期値をなぞり式に変更。新規描画の指オフセットを画面px基準・Y方向のみで統一し、手動モードの常設説明を「?」ボタンのポップアップへ移動。


V87: 黒塗り文字の履歴チップを追加。隠し方として黒塗り / 背景色 / ぼかし / 任意色を追加。スタンプモードでは新規配置時のオフセットを無効化し、タップ位置に置けるよう調整。


V87.1: 初期化順序を修正し、画像選択後も「画像を選択してください」となる不具合を解消。手動ヘルプの?ボタンを28pxに縮小。


V87.2: ぼかしをiOS Safariでも効きやすい縮小→滑らか拡大方式へ変更。2つのプルダウン幅を同じコンパクトサイズに統一。任意色のカラーピッカー領域を常時確保し、表示時にUIが動かないよう調整。


V89: V88/V88.1系の重い実験は採用せず、イタリック寄せの軽量診断だけを追加。イタリックテンプレート / 元画像 と コントラスト補正→イタリックテンプレート の2系統のみを診断比較する。診断専用で本番黒塗りには未接続。


V90: イタリック寄せの軽量診断を発展させ、コントラスト補正後の画像に対してテンプレート高さ 30/32/34px と傾き 0.00/0.08/0.16 の少数バリエーションを試す多段診断を追加。粗探索(step 6)→局所再探索(step 2)で速度を抑えつつ、由良/真緒のような字形差に対応しやすくした。診断専用で本番黒塗りには未接続。


V90.1: V90で実績のあったH32/H34・skew 0.00だけに軽量化。コントラスト補正→イタリック候補のうち、score>=0.64 / 文字>=0.50 / 背景>=0.94、かつ既存OCR候補と重複しないものを最大3件まで補助黒塗りとして統合するテスト。


V90.2: V90.1の調整版。H32/H34・skew 0.00 は維持したまま、粗候補上限を 10 件、最終候補上限を 6 件に拡張。局所再探索の範囲を ±10px に拡大し、コントラスト＋イタリックの探索閾値と本番救出閾値を少し緩和して、あと1件の取りこぼし救出を狙うテスト。


V90.3: V90.2の格子補正版。粗探索6pxは維持しつつ、通常格子に加えて3pxずらした第2格子でも探索し、X/Yの探索末尾位置を必ず1回は走査するように変更。スキャン間隔による飛び越しと末尾取りこぼしの確認用テスト。


V90.4: V90.3のイタリック救出を本番の自動黒塗り補助として継続採用。置き換え文字/黒塗り上テキスト機能をUI・描画・設定保存から削除。また、V63文字単体テンプレート、V82.1かな救出、V86旧Canvasテンプレート、V70文脈救出など本番で使っていない旧診断コード/表示を整理し、診断処理を軽量化。


V90.5: V90.4の診断画面に残っていたtemplateResult参照を削除してReferenceErrorを修正。自動OCR黒塗りのサイズが少し大きめだったため、左右余白2→1px、最低padding3→2px、padding比率8%→6%へ保守的に縮小。V90.3由来の3pxずらし格子・末尾保証・H32/H34イタリック救出はそのまま維持。


V90.6: 自動検出後の描画で style 引数が黒塗り扱いになっていた不具合を修正。これにより自動検出でも「黒塗り / ぼかし / 任意色」の現在設定が反映される。また、OCRの2文字完全一致で片方のsymbol bboxだけが壊れているケース向けに、妥当な方の文字bboxから控えめに幅を推定する補正を追加し、「真緒に変身」で「に変身」まで巻き込むような過大黒塗りを抑制。


V90.7: 自動黒塗りの左境界制約が1文字目のbbox内に入り込み、先頭文字（例: ネ / 真）が少し見えてしまうケースを抑制。左境界は1文字目bboxの手前で必ず止めるように修正。あわせて、診断の緑枠を生OCRの target bbox ではなく、実際に塗られる最終矩形表示へ変更。


V90.8: 速度優先調整。完全一致HITすべてに行っていた高倍率周辺再OCRを、symbol bboxが怪しい箇所だけに限定。正常そうなHITは再OCRを省略し、検出ルート・局所OCR・イタリック救出・3pxずらし格子・末尾保証は維持。


V90.9: iPhone Safariの速度・クラッシュ対策。グレー＋コントラストHITが0件の時に実行していた二値化180/220/反転の全画面OCR 3連打を本番経路から省略。代わりに色抽出OCR、候補再OCR、文字領域局所OCR、イタリック救出を維持。さらに大きな縦長画像ではOCR用2.5倍キャンバスを約1100万pixel以内になるよう自動縮小し、メモリ使用量を抑える。通常サイズ画像は従来どおり2.5倍。


V90.10: run()でcollectOcrResultsのstatsを受け取っていなかったため、処理完了時のstatus表示でReferenceErrorになる不具合を修正。また、イタリック診断のオレンジ枠を生候補すべてではなく、本番採用閾値(score/形状/背景)を通った候補だけに変更。診断テキストには生候補を残し、本番採用候補数も追加表示する。


V90.11: 3文字対象の近似候補救出を追加。3文字は1文字誤認すると類似度が67%に落ち、従来の72%閾値では救出できなかったため、同じ長さ・編集距離1・類似度66%以上に加え、同一地点で同じ誤認文字列が2回以上出た場合だけ採用する安全寄りルールを追加。例: コカゲ→コカグ。救出が成立した地点は局所再OCRを省略するため速度改善にもなる。


V90.12: V90.11では「同じ地点で同じ誤認が2回以上」を条件にしていたが、コカゲ→コカグの実例ではコカグが2回出ていても別々の候補地点に1回ずつだったため救出されなかった。3文字・編集距離1・類似度66%以上について、同一誤認文字列が画像内の別候補地点で2地点以上出た場合も近似候補救出する全体コンセンサスを追加。同一group内の重複は1票として数える。


V90.13: UI整理。履歴は最大5件に変更。履歴直下に自動検出・手動・戻す・リセット・OCR診断を配置。その下に折りたたみ式「オプション」を追加し、手動の描画方法→隠し方→スタンプモードの順に収納。スタンプモード横の説明文は削除し、手動モードのヘルプポップアップ内へ移動。


V90.14: 画像サイズ/表示倍率差への対応テスト。文字領域検出の高さ中央値から実文字高さを推定し、イタリックテンプレートは固定32/34pxではなく推定値±2pxの2サイズだけを探索。31〜35px推定時は実績のある32/34pxを維持。追加OCRは行わず既存の文字領域検出結果を再利用して速度増加を抑える。手動なぞり式は元画像32px固定から「100%表示時に約32CSS px」基準へ変更し、高解像度画像では自動的に太くする。スタンプモードを折りたたみ外へ戻し、手動描画/隠し方のプルダウン高さを38pxで統一。


V90.15: Gemini案をそのままではなく既存対策と両立する形で3点テスト。①2文字のうち2文字目だけbboxが妥当な場合、2文字目からの逆算だけで左端を右へ送りすぎないよう、元target bboxと1文字目bboxを安全な左端候補として保持。②primary HIT=0時の全画面fallbackは3連打に戻さず、強い近似候補がなくOCRキャンバス850万pixel以下の時だけ二値化180を1回実行。③文字領域局所OCRは既存HIT/近似救出の大半を含む領域をスキップし、重複OCRを削減。V90.14の可変テンプレート、手動なぞり自動高さ、UI整理は維持。


V90.16: V90.15で「コカゲ」が0 HITになったため切り分け。追加の二値化180全画面OCRと既存HIT領域スキップをいったん撤回し、V90.12/14系の近似候補→3文字グローバル合意→局所OCRの流れへ戻した。V90.15の2文字左端ドリフト保護は維持。手動なぞり高さは表示サイズ連動を維持しつつ32〜44px相当に制限。PCマウス編集ではpointerup時にドラッグ状態を必ず終了し、buttons=0のpointermoveとlostpointercaptureも安全停止することで、黒塗りがカーソルへ追従し続ける症状を修正。
