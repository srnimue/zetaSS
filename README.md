# スクショ黒塗りツール V82

V76の「OCR前に白枠10px」をベースにした、V81かな誤認識救出の位置確認用診断版です。

## V82で追加した実験
- V81で検出した「かなの1文字置換による誤認識候補」を、診断時に画像上へ赤枠で仮表示。
- ラベルに「OCR候補 → 対象文字」を表示し、候補bboxが実際に対象文字を覆っているか目視確認できるようにした。
- V82の候補は診断専用で、通常の自動黒塗りには使用しない。
- V81までのOCR・手動黒塗り機能は変更しない。

## 使い方
1. 画像を選択
2. 対象文字を入力
3. 「OCR診断」を実行
4. 診断結果の「V81 誤認識救出診断（かな）」を確認
5. 画像上に表示される赤枠「V82候補」を確認
6. 赤枠が実際の対象文字を覆っているかを確認

通常の黒塗り処理はV76相当のままです。
