# zetaSS V82.1

V81をベースにした診断版。
- かな誤認識候補を黒塗りには使用せず、候補bboxを赤枠で仮表示
- 診断見出しをV82.1へ更新
- 色抽出OCRを主OCRのHIT数に関係なく補助実行し、退行確認用にHIT数を表示
- 既存の手動黒塗り・OCR黒塗り処理は変更しない


V86.1: 手動描画の初期値をなぞり式に変更。新規描画の指オフセットを画面px基準・Y方向のみで統一し、手動モードの常設説明を「?」ボタンのポップアップへ移動。


V87: 黒塗り文字の履歴チップを追加。隠し方として黒塗り / 背景色 / ぼかし / 任意色を追加。スタンプモードでは新規配置時のオフセットを無効化し、タップ位置に置けるよう調整。


V87.1: 初期化順序を修正し、画像選択後も「画像を選択してください」となる不具合を解消。手動ヘルプの?ボタンを28pxに縮小。


V87.2: ぼかしをiOS Safariでも効きやすい縮小→滑らか拡大方式へ変更。2つのプルダウン幅を同じコンパクトサイズに統一。任意色のカラーピッカー領域を常時確保し、表示時にUIが動かないよう調整。


V89: V88/V88.1系の重い実験は採用せず、イタリック寄せの軽量診断だけを追加。イタリックテンプレート / 元画像 と コントラスト補正→イタリックテンプレート の2系統のみを診断比較する。診断専用で本番黒塗りには未接続。


V90: イタリック寄せの軽量診断を発展させ、コントラスト補正後の画像に対してテンプレート高さ 30/32/34px と傾き 0.00/0.08/0.16 の少数バリエーションを試す多段診断を追加。粗探索(step 6)→局所再探索(step 2)で速度を抑えつつ、由良/真緒のような字形差に対応しやすくした。診断専用で本番黒塗りには未接続。


V90.1: V90で実績のあったH32/H34・skew 0.00だけに軽量化。コントラスト補正→イタリック候補のうち、score>=0.64 / 文字>=0.50 / 背景>=0.94、かつ既存OCR候補と重複しないものを最大3件まで補助黒塗りとして統合するテスト。


V90.2: V90.1の調整版。H32/H34・skew 0.00 は維持したまま、粗候補上限を 10 件、最終候補上限を 6 件に拡張。局所再探索の範囲を ±10px に拡大し、コントラスト＋イタリックの探索閾値と本番救出閾値を少し緩和して、あと1件の取りこぼし救出を狙うテスト。


V90.3: V90.2の格子補正版。粗探索6pxは維持しつつ、通常格子に加えて3pxずらした第2格子でも探索し、X/Yの探索末尾位置を必ず1回は走査するように変更。スキャン間隔による飛び越しと末尾取りこぼしの確認用テスト。


V90.4: V90.3のイタリック救出を本番の自動黒塗り補助として継続採用。置き換え文字/黒塗り上テキスト機能をUI・描画・設定保存から削除。また、V63文字単体テンプレート、V82.1かな救出、V86旧Canvasテンプレート、V70文脈救出など本番で使っていない旧診断コード/表示を整理し、診断処理を軽量化。


V90.5: V90.4の診断画面に残っていたtemplateResult参照を削除してReferenceErrorを修正。自動OCR黒塗りのサイズが少し大きめだったため、左右余白2→1px、最低padding3→2px、padding比率8%→6%へ保守的に縮小。V90.3由来の3pxずらし格子・末尾保証・H32/H34イタリック救出はそのまま維持。
